Сделаны задачи 1, 2 и 5, каждая — отдельная программа на C++.

## Задача 1 — обмен значений (task1_swap.cpp)

Даны две переменные a и b. Поменять их значения местами, не объявляя
третью переменную. Разрешены только присваивание и арифметика.

Решение: через сумму. После `a = a + b` в a лежат оба числа сразу,
дальше вычитанием достаём из неё сначала старое a, потом старое b.

## Задача 2 — произведение факториалов (task2_superfactorial.cpp)

Вычислить F(n) = 1! * 2! * 3! * ... * n! за один цикл.

Решение: в переменной f хранится текущий факториал. Каждый следующий
получается из предыдущего умножением на i, поэтому пересчитывать
факториал с нуля не нужно и вложенный цикл не требуется.
В res копится произведение этих факториалов.

Начиная с n = 9 результат не помещается в unsigned long long.

## Задача 5 — недостающее число (task5_missing.cpp)

В неупорядоченном массиве лежат n различных чисел от 0 до n, одно число
пропущено. Найти его за один цикл.

Решение: сумма всех чисел от 0 до n равна n * (n + 1) / 2. Реальная сумма
массива меньше ровно на пропущенное число, поэтому ответ — их разность.
Сумма считается прямо во время ввода, второй проход не нужен.
