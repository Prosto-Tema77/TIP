# TIP
Технологии индустриального программирования

## Как запускать (VS Code)

Нужны расширения C/C++ и Code Runner. VS Code сам предложит их при открытии папки.

- ▷ справа сверху или ⌃⌥N — собрать и запустить файл из открытой вкладки.
- F5 — отладка файла из открытой вкладки.

Программы собираются в папку `build/`, она не попадает в git.
