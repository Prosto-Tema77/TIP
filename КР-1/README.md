## Задание 3 — значение выражения (zadanie3.cpp)

Выражение по варианту: 8(6x - 7) - 17x.

Перед записью в программу выражение упрощено:
8(6x - 7) - 17x = 48x - 56 - 17x = 31x - 56.
Программа считывает x с клавиатуры и выводит значение 31x - 56.

## Задание 4 — квадратный многочлен (zadanie4.cpp)

Программа считывает коэффициенты a, b, c многочлена ax^2 + bx + c,
затем символ команды:

- `Q` — выводит фамилию и имя студента на английском;
- `d` — выводит корни многочлена. Отдельно разобраны случаи a = 0
  (линейное уравнение), a = b = 0 (корней нет или x — любое число)
  и знак дискриминанта;
- `g` — запрашивает стоимость и скидку в процентах и выводит
  стоимость покупки с учётом скидки.
